# Iteration 09 — Cases filters drawer and applied chips

## Goal
Reduce visual overload on the Cases screen while preserving full filtering power.

## Scope
- Keep search and sorting visible in the top toolbar.
- Move advanced filters into a collapsible Filters drawer.
- Show applied filters as removable chips outside the drawer.
- Preserve filter and sort state in the URL.

## Outcome
Cases remains a readable registry first and a filter workspace second.
