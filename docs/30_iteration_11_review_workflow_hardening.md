# Iteration 11 — Review Workflow Hardening

## Goal
Tighten the daily review loop without leaving the follow-up control design.

## Included
- quick review views in Cases (`Needs action`, `Paid but open`, `Stale`, `Reminder issues`)
- mandatory outcome reasons for `done` / `lost`
- `Reopen case` action from item detail
- stronger `Next action` visibility in Cases and item detail

## Excluded
- client entities
- team workflows
- CRM-style pipelines
