# Issue workflow

Until a GitHub Project board is available, the first tag in each issue title records its status:

- **[Backlog]** — accepted work without a scheduled start.
- **[Ready]** — clear scope and acceptance criteria; can be picked up.
- **[In Progress]** — work is underway.
- **[Review-QA]** — implementation is complete and needs review or verification.
- **[Done]** — acceptance criteria are verified and the issue is closed.

Use GitHub's standard `bug`, `enhancement`, and `documentation` labels for issue type when available. Update the title tag as work advances. When a GitHub Project is added, use these same five statuses and link the existing issues.
