# Iteration 10 — Review signals

## Goal
Surface follow-up risks without expanding the product into CRM workflow software.

## Signals added
- Paid but case still open
- No activity for 7+ days
- Reminder delivery failed
- Overdue without reminder sent

## Surfaces
- Cases registry rows
- Item detail state block
- Cases filter drawer via Review signal filter

## Outcome
Problematic cases become visible without widening the domain model.
