# Iteration 13 — Activation UX hardening

## Goal
Reduce first-session friction and help a new user reach value in one pass.

## Added
- Activation summary endpoint for authenticated users.
- Sample case bootstrap endpoint.
- Dashboard activation checklist and sample-case CTA.
- Cases empty-state CTA for sample-case creation.
- Billing trial notice on Dashboard.

## Why
The product should guide first use without adding CRM scope or hidden complexity.
